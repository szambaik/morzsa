# Fast recipe images — 2026-11-17

New fal.ai jobs use `fal-ai/flux-2/klein/4b`, at 768 × 512, four inference steps, one JPEG and the safety checker enabled. The generic recommendation label has been removed from chat recipe cards; meaningful crafting/completion labels sit below the image. The AI illustration attribution stays visible.

## Request flow and compatibility

- Recipe generation produces an optional English `imagePrompt` alongside the recipe. Both the regular assistant and Plus use the recipe schema. Local sanitization and existing JSON storage preserve the field without a database migration.
- Cover generation reuses a bounded description without another Groq call. Old recipes and individual cooking steps keep the existing translation path; a finished-dish description is never used for a preparation step.
- Image metadata is excluded from the legacy image cache key. Ready images are reused, including images generated by earlier models.
- Each new fal handle records its model. Existing Schnell handles without a model still poll the original endpoint and settle against the old cost estimate. Transient failures do not resubmit requests. Queue URLs remain restricted to the matching model and request ID on `queue.fal.run`.
- The first four pending-status checks wait 750 ms each, the next four wait 1.5 seconds, then polling backs off to 4 seconds within the existing 90-second window. Leaving the view stops further checks; generation is not repeated.

## Configuration and rollout

`FAL_KEY` stays server-side. `FAL_IMAGE_MODEL` is optional and defaults to `fal-ai/flux-2/klein/4b`; the allowed rollback value is `fal-ai/flux/schnell`. Existing `PLUS_IMAGE_PROVIDER` and `CATALOGUE_IMAGE_PROVIDER` routing remains in effect. Free personal images retain the Cloudflare route and existing quotas.

To activate the complete change, deploy the frontend through the existing Pages gate and deploy these Supabase functions from the same revision: `recipe-image`, `recipe-ideas`, `voice-command`, and `plus-assistant` (which imports the assistant schema). A frontend deployment alone does not change the hosted image model. No new SQL migration is required for this change.

The published fal price is $0.005 per megapixel for Klein 4B. Quota accounting uses a conservative estimate of 0.5 US cents for this image size, retaining 0.3 cents for old Schnell jobs and the existing one-cent reservation. This is an application estimate, not provider-reported billing.
