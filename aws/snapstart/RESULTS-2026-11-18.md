# Valódi AWS runtime-mérés, 2026-11-18

Az AWS MCP-n keresztül eu-north-1 régióban telepített, elkülönített
morzsa-snapstart-pilot mindhárom függvénye sikeresen működik. Mindegyik
256 MB, x86_64, published version 1, probe alias, VPC és Provisioned
Concurrency nélkül. A két Java-verzió ugyanazt az 1482 bájtos ZIP-et futtatja;
a Node ZIP 477 bájt. A SnapStart OptimizationStatus ténylegesen On.

| --- | --- | --- | --- |
| Java 21 SnapStart | restore 475,53 ms, 1 esemény | 303,00 ms | 1,49 ms |
| Java 21 | init 373,71 és 366,56 ms, 2 esemény | 249,61 ms | 1,43 ms |
| Node 22 | init 139,71 ms, 1 esemény | 4,01 ms | 1,37 ms |

45 meghívás: változatonként 1 első, 10 szekvenciális, 4 párhuzamos hívás.
Minden SHA-256 válasz egyezett a Unicode bemenetével, és mind a 45 UUID
egyedi volt. A burst önmagában nem garantál új környezetet. A hiányzó
init/restore mérések null értékek, nem nulla időtartamok.

Az MCP-szerver teljes SDK-hívásidejének szekvenciális mediánja 581 / 574 /
562 ms volt. Ez eszköz- és hálózati többletet is tartalmaz, nem a telefonból
vagy a kész API-n keresztül mért késleltetés. A fenti táblázat a Lambda saját
REPORT és RESTORE_REPORT értékeit mutatja.

Következtetés: ehhez a minimális feladathoz a SnapStart nem adott előnyt.
A Morzsa gyakori API-jának első implementációját kis Node-csomagokkal
érdemes kezdeni. Az auth/DB/AI függőségekkel később külön mérés kell.

A költségterv ellenőrzésekor a projekt FREE / ACTIVE csomagban volt,
100 USD felhasználható kredittel, 2027-05-18-i lejárattal. A kredit nem
azonos a szolgáltatások saját ingyenes keretével. A Java SnapStartnak nincs
külön snapshot/restore díja; a hívások, futás, naplók és tárolás mértek.
Tényleges számlaösszeg még nem áll rendelkezésre.

Létrejött a morzsa-probe-artifacts stack privát, AES256 titkosított,
verziózott bucketje is. Az artefaktumok hét nap után lejárnak; a bucket
Retain szabályú, stacktörléskor önmagában megmarad. Nincs benne appadat.
A próba takarításáról a felhasználó dönt.

Ellenőrzés: Node/Java helyi sanity, cfn-lint, S3 Guard PASS, AWS template
validáció, sikeres CloudFormation CREATE_COMPLETE állapotok, 45 validált
AWS-hívás. A már elindított teljes release gate is sikeresen lefutott.
Az alkalmazás nem lett publikálva, a Supabase nem változott.

A részletes, titkok és nyers naplók nélküli minták a helyi, ignorált
build/snapstart-results.json fájlban vannak.
