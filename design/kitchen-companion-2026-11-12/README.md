# Kitchen Companion adoption — 2026-11-12

Selected by the user: the first Kitchen Companion concept, with the warmer
gradient treatment from Soft Glass. This is an evolution of the working app;
the concept's sample AI and household data are not part of production.

The navigation order is Overview, Pantry, Morzsa, Shopping list, Recipes.
Morzsa remains the launch screen and occupies the central mobile tab. Desktop
navigation and the existing conversation history share one permanent sidebar.
Mobile history can be opened from every section without first leaving it.

Two compact actions by the composer open the same quick-add sheet everywhere,
including inside a recipe conversation. Commas and Enter collect entries;
autocomplete uses the existing catalog, aliases and custom products. Saving
keeps the current section and scroll position. Adding an item already present
does not increase its shopping quantity, and recipe associations survive.

Pantry membership is approximate availability. No exact stock quantities,
new household schema, new RPC or automatic import is introduced. Shared list
edits use the existing persisted outbox; pantry edits and confirmations use
the existing save paths and review metadata. Failed quick-add saves retain the
batch. Drafts are scoped to the current account and household.

The original Sora/Inter typography, food illustrations and mascot are retained.
Lucide icons are sourced assets with their upstream notice. Static cream,
terracotta and sage gradients provide warmth; blur is limited to the small
navigation surface. Reduced motion and reduced transparency are respected.

Original source and artwork permissions are now described in the root LICENSE
and ASSET-LICENSE.md. Third-party photographs, icons, fonts and dependencies
retain their upstream licenses. Both web and mobile bundles include the notices.
