# Supplied recipe-page visual reference

Brand, mascot, calendar and jar illustrations were extracted from the user's
2026-11-19 recipe-page mockup. The exact source is preserved under
design/recipe-page-2026-11-19/reference.png.

Food-photo crops are used only by the explicitly enabled local SQL design
fixture. Embedded mockup heart controls were locally repaired so they cannot
appear underneath real buttons at different viewport sizes. Production recipe
photos continue through the existing scoped RecipeImages/backend cache.

The icons/ SVG files are Phosphor Icons core 2.1.1 regular variants, downloaded
from the published package. Their MIT license is included beside the files.
No icon shapes or illustrations were drawn in HTML/CSS.
