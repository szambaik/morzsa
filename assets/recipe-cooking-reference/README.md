# Cooking reference assets

The oatmeal step photo is an exact crop from the user's supplied cooking mockup
(552,330)-(1135,606). The cover and finished-dish crops are in
../cooking-page-reference. These food photos appear only when the explicitly
opted-in, isolated cooking QA fixture is enabled. Production images continue to
use RecipeImages and the backend/device cache.

Icons are Phosphor Icons Core 2.1.1, regular style, fetched from the official
package distribution. MIT license is included. check-white.svg is the same
licensed check path with a white fill for the green checklist controls.
